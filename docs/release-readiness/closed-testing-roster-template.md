## Target

- 目标邀请：15-20 人。
- 若 Play Console 账号适用新个人开发者要求，目标是至少 12 名 tester 连续 opt-in 14 天。
- 覆盖设备：至少一台国产 Android、一台 Pixel / 原生系统、一台蓝牙耳机或音箱场景。

## Review Cadence

- Day 0：确认 tester 已收到 opt-in 链接和测试说明。
- Day 2-3：确认安装成功率、启动问题和前 3 个 P0/P1 反馈。
- Day 7：确认活跃 tester 数和中期反馈主题。
- Day 12-14：确认连续 opt-in 风险，整理 production access 素材。
