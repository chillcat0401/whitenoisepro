# Closed Testing Feedback Tracker

状态：模板。真实用户反馈可能包含个人信息，不应提交到公开仓库；公开仓库仅保存汇总和脱敏记录。

## Severity

| 级别 | 定义 | 处理 |
| --- | --- | --- |
| P0 | 崩溃、无法播放、无法停止、严重隐私/权限误导 | closed testing / production access 阻断 |
| P1 | 后台播放中断、timer 不可信、明显刺耳 loop、主流程无法理解 | closed testing 前优先修复或记录明确接受理由 |
| P2 | UI 拥挤、文案不清晰、分类不符合预期、设置困惑 | closed testing 中可迭代 |
| P3 | 偏好建议、声音建议、未来功能 | backlog |

## Required Feedback Questions

请每位 tester 至少回答：

- 哪一步让你困惑？
- 声音是否舒适，有无明显循环断点？
- 后台播放是否稳定？
- 30/45 分钟入睡 timer 是否容易找到？
- 你是否愿意睡前继续使用？
- 是否有任何文字、按钮或权限说明不可信？
- 使用手机扬声器、耳机或蓝牙设备时是否有明显差异？
