## Play Console 对齐项

- 开发者名称必须与 Play Console 账号资料和商店详情一致。
- 支持邮箱必须可收信，且可用于 tester / 用户反馈。
- 隐私政策 URL 必须公开可访问，不应是 PDF，不应需要登录，不应被地理封锁。
- 如果未来加入账号、云同步、客服表单、analytics、crash reporting、billing 或广告 SDK，本模板、隐私政策和 Data safety 必须同步更新。

## Store Listing 文案边界

允许表达：

- 白噪音、助眠声音、专注背景声。
- 本地打包声音。
- 无账号、无广告、偏好本地保存。
- 后台和锁屏媒体控制。

避免表达：

- 治疗、治愈、改善失眠、医学效果或保证入睡。
- 与实际代码不一致的数据收集、联网、下载或账号能力。
- 未确认的开发者资质、认证、奖项或排名。
