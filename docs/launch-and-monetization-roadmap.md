## 2. 盈利规划(核心观点:广告不是这个品类的主菜)

**关键事实:白噪音 App 的使用场景是熄屏后台播放,广告曝光天然极低;睡眠场景插全屏广告会直接杀死留存。** 头部产品(Calm、BetterSleep)全部以订阅为主。建议三阶段:

### Phase 1 · 上架即接(与生产发布同步):轻广告 + 一次性买断

- **AdMob**:仅两个位置——声音库网格中的原生卡片广告(1 个)+ 「激励视频解锁高级声音 24h」。**不放横幅、不放插屏**。
- **一次性买断 IAP(Pro 解锁,$5.99–$9.99)**:去广告 + 解锁全部声音 + 不限混音保存槽位。买断制在工具型睡眠 App 中转化远好于直接上订阅,且实现量小(Play Billing 单 SKU)。
- 免费版策略:19 个声音中保留 8–10 个免费(覆盖各分类),混音槽免费 3 个。

### Phase 2 · 1–2 个月:订阅制 + 内容飞轮

- 订阅($2.99/月、$19.99/年,买断用户自动豁免):每月新增主题声景包(秋雨、车厢、咖啡馆…)、组合混音预设、节律淡入淡出等。
- 内容生产已有管线(`tools/generate_mvp_audio.mjs` + Freesound CC0 流程),边际成本接近零——这是这个项目最重要的盈利杠杆。
- ASO 多语言:声音 App 文案极少,低成本翻译 10+ 语言商店页,吃自然量(白噪音搜索量大、竞争分散)。

### Phase 3 · 3–6 个月:抬高客单与场景扩展

- 睡眠仪式功能:呼吸引导、定时唤醒柔和闹钟、宝宝哄睡模式(白噪音品类最大付费人群之一是新手父母)。
- 数据看板:连续使用天数、入睡时长趋势(纯本地,不碰隐私红线)。
- 评估出海第二平台:iOS(KMP 架构已就绪,`commonMain` 占比高,补 iosMain 播放引擎即可)。

### 指标门槛

- 广告决策:若 D30 广告 ARPDAU < $0.01(大概率),果断把广告降为纯激励视频,全力推买断/订阅。
- 订阅决策:买断转化率 > 1.5% 且 MAU > 1 万再上订阅,避免过早分裂定价。

## 3. 鸿蒙(HarmonyOS NEXT)+ 中国大陆上架

### 3.1 先启动长周期合规事项(本周内就办,与开发无关)

| 事项 | 周期 | 说明 |
|---|---|---|
| **软件著作权(软著)** | 普通 1–2 月,加急 5–15 工作日(数百到几千元) | 华为 AGC 上架硬性要求,**今天就可以提交申请** |
| **App 备案(工信部)** | 1–4 周 | 需备案主体(个人可办)+ 已备案域名;隐私政策需挂在该域名下 |
| **华为开发者实名认证** | 1–3 天 | 个人可上架免费 App;**但接入华为 IAP/广告联盟收款需企业开发者资质** |
| 隐私合规(个保法) | 与开发并行 | 首次启动隐私弹窗、个人信息收集清单、第三方 SDK 目录 |

**结论:若以个人身份做鸿蒙版,变现只能先做免费引流;要在大陆收钱,需要企业主体(或挂靠)。这是商业决策点,建议尽早定。**

### 3.2 技术路线:ArkTS 原生重写(推荐)

HarmonyOS NEXT 不兼容 Android,KMP 无官方鸿蒙 target。三个选项:

1. **ArkTS/ArkUI 原生重写(推荐)**:本 App 逻辑极薄(目录、混音状态、定时器、播放),UI 共 5 页。ArkUI 声明式写法与 Compose 高度同构,`Screens.kt` 几乎可逐页翻译;音频用 AVPlayer + 后台长时任务(continuousTask)+ AVSession,对标现有 MediaSession 实现。预估 2–3 周。
2. Tencent Kuikly(Kotlin 复用):可复用 commonMain 逻辑,但生态早、踩坑风险大,不值得为这点逻辑量冒险。
3. Flutter-OpenHarmony 分支:等于引入第三套技术栈,排除。

### 3.3 排期建议

- 6 月内:软著 + 备案 + 实名认证全部提交(等待期免费)。
- 7 月(Google Play 生产发布后):ArkTS 版开发 2–3 周,UI 直接复用本次新设计规范(深海蓝体系是现成的设计交付物)。
- 8 月初:华为 AGC 提审上架(免费版先行),变现待企业资质落地后接华为 IAP。
- 顺带收益:同一套 ArkTS 包稍作渠道适配即可铺小米/OPPO/vivo/应用宝等安卓国内商店(同样吃软著+备案这套合规件)。
