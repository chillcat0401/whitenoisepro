Overview

WhiteNoisePro is a white noise and sleep sounds app. The current release provides local sound playback, mixes, a sleep timer, saved mixes, settings, and background media controls.

Data Collection

The current release does not collect personal data from users. It does not include user accounts, advertising SDKs, analytics SDKs, crash reporting SDKs, billing, cloud sync, social SDKs, location features, microphone access, camera access, contacts access, or photo library access.

Preferences and saved mixes are stored locally on your device. They are not uploaded to a developer server.

Local Data

The app may store local settings such as current mix, saved mixes, recent mixes, timer settings, theme preferences, audio quality preference, offline download preference, and haptics preference. You can delete this local data by uninstalling the app or clearing app storage in Android settings.

Audio Sources

The current release uses audio files bundled inside the app. It includes first-party generated noise assets and processed Creative Commons 0 external recordings. The app does not require users to provide audio files and does not request recording permissions.

Permissions

The app uses Android foreground media playback capabilities to support background and lock-screen audio playback. These media controls are not marketing notifications. The current manifest does not request POST_NOTIFICATIONS.

Sharing

The current release does not share personal data with third parties.

Future Changes

If future versions add accounts, cloud sync, analytics, crash reporting, advertising, billing, customer support systems, or other SDKs that process user data, this policy and the Google Play Data safety answers will be updated before release.
