# 小雨音频候选探索

## 用户反馈

用户选择 `rain-natural` 2 号作为较好的雨声候选，但反馈整体仍偏“暴雨”。因此需要区分“小雨”和现有 `rain` 候选。

## 判断

当前 `rain` profile 适合作为中到大雨、密集雨幕或雨林背景候选。若继续在同一 profile 内压低强度，会让 `rain` 的语义不稳定。更合适的是新增内部候选 profile：`light-rain`。

## 方案比较

### 方案 A：继续调低 `rain`

- 优点：改动少。
- 缺点：会破坏已选中的 `rain-natural` 2 号作为“大雨/密集雨幕”候选的价值。

### 方案 B：新增 `light-rain` 候选 profile

- 优点：明确区分小雨和中大雨；后续 App catalog 可以分别命名为“小雨”“雨幕”。
- 缺点：需要扩展 supported profiles、测试和文档。

## 推荐

采用方案 B：新增 `light-rain`。目标是更稀疏、更远、更柔和，减少低频雨幕冲击和高频密集喷流感。
